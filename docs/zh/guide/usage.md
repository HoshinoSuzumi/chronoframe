# 日常使用

## 上传和整理照片

登录后访问 `/dashboard`，在照片页选择文件或拖入文件，支持批量上传。上传完成后，后台继续提取 EXIF、生成缩略图并识别拍摄地点；可以在任务队列中查看进度、失败原因和重试结果。

- 照片表格支持排序、筛选和自选显示列，并记住列的显示状态，也支持按上传日期排序。
- 选中照片后可以批量删除、下载、重新索引或加入相册。支持 Shift + 单击连续选择。
- 编辑照片可以修改标题、描述、评分等元数据。
- Apple Live Photo 的照片和 MOV 文件使用同一文件名，例如 `IMG_1234.heic` 和 `IMG_1234.mov`。上传顺序不限，配对失败时可在后台重新处理。
- 也支持带有嵌入视频的 Motion Photo。大图由 WebGL 查看器显示，支持平移、缩放和分块渲染。

## 相册和可见性

相册可将同一主题的照片集中展示，支持相册排序和相册内照片排序。

隐藏相册用于限制公开展示，同时限制匿名访客访问其中的照片，即使该照片还属于公开相册；请在调整可见性后检查公开画廊的结果。

也可以为相册设置密码，密码至少 6 个字符。访客需要解锁才能在 ChronoFrame 中查看相册内容，分享其中照片时也会保留相册访问范围。

::: warning 外部存储的访问边界
相册密码限制的是 ChronoFrame 内的访问。S3、OpenList 或 CDN 如果提供可直接访问的图片地址，知道地址的人仍可能绕过相册页面读取文件。需要保护文件本身时，应同时检查存储服务和 CDN 的访问策略。隐藏相册也不能收回已经公开的外部链接。
:::

## 在后台修改设置

站点信息、地图、位置服务、存储和上传限制均可在后台修改。设置保存在数据库中；无需编辑 `.env` 或重建容器。

| 设置 | 用途                                                      |
| ---- | --------------------------------------------------------- |
| 站点 | 名称、介绍、作者、头像和明暗主题                          |
| 存储 | 新增和编辑本地、S3、OpenList 存储方案，选择当前使用的方案 |
| 地图 | MapLibre / Mapbox、访问令牌和地图样式                     |
| 位置 | 地名语言、Mapbox 反向地理编码令牌、自定义 Nominatim 地址  |
| 系统 | 单文件上传大小、重复文件处理、GitHub 登录                 |
| 隐私 | 上传时自动移除位置信息                                    |
| 分析 | 注入到页面 head 或 body 的自定义统计脚本                  |

地图负责显示，位置服务负责将 GPS 坐标转换成地名，两者分别设置。更改地名语言后，已有照片需要重新索引位置才能更新保存的地名。

更换存储方案前，请确认已有照片仍能访问。选择新方案不等于将原图自动搬到新存储中。本地存储路径必须位于已挂载的目录内，容器才能在重建后继续访问文件。

隐私设置影响之后的上传，不会自动清理过去上传的文件。已有照片可以在照片管理中单独或批量执行移除位置信息，并在任务队列中确认完成。公开前也应检查照片描述和标签是否含有不希望分享的信息。

## GitHub 登录

先使用向导创建的邮箱和密码登录，再在系统设置中开启 GitHub OAuth，填写 Client ID 和 Client Secret。OAuth 应用的回调地址填写 `https://你的域名/api/auth/github`。

GitHub 返回的邮箱需要匹配已有管理员的邮箱。启用 OAuth 不会让任意 GitHub 用户成为管理员；未获授权的账号会被拒绝登录。

## 排查上传问题

任务队列显示处理进度和失败原因，日志页可以查看实时日志和历史记录。遇到上传被拒绝时，先核对应用和反向代理的文件大小限制；遇到存储失败时，检查目录写入权限或远端凭据。反馈问题时附上版本号、使用的存储类型和相关日志，并去掉令牌、密钥等私人信息。
